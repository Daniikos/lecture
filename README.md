# Конспекты лекций

Лекции пишутся от руки, распознаются и набираются в LaTeX. Здесь хранится
исходник; PDF собирается автоматически.

## Курсы

| Курс | Папка | Описание |
|------|-------|----------|
| Математический анализ | [`matan/`](matan/) | [оглавление лекций](matan/README.md) |
|------|-------|----------|
| Математический анализ | [`TF/`](TF/) | [оглавление лекций](matan/README.md) |

## Как читать

Готовые PDF лежат в релизе
[`latest`](https://github.com/Daniikos/lecture/releases/tag/latest) —
он пересобирается при каждом изменении в `main`. Файлы называются
`<курс>-<дата>.pdf`, например `matan-2026-09-02.pdf`.

Установка TeX для чтения не нужна.

## Структура

```
lecture/
├── matan/                  один каталог — один курс
│   ├── README.md           оглавление: дата → тема → файл
│   └── 2026-09-02.tex      одна лекция — один файл, имя = дата лекции (ГГГГ-ММ-ДД)
├── TF/                  один каталог — один курс
│   ├── README.md           оглавление: дата → тема → файл
│   └── 2026-09-03.tex      одна лекция — один файл, имя = дата лекции (ГГГГ-ММ-ДД)
├── .github/
│   ├── workflows/build.yml сборка PDF на каждый PR и публикация в релиз latest
│   └── PULL_REQUEST_TEMPLATE.md
├── .vscode/                общие настройки VS Code + LaTeX Workshop
├── .editorconfig           UTF-8, LF, отступ 2 пробела — для любого редактора
├── .gitattributes          принудительный LF для исходников
├── .gitignore              мусор сборки и IDE
└── CONTRIBUTING.md         как вносить правки
```

Имя файла — дата в формате ISO (`ГГГГ-ММ-ДД`), а не `ДД_ММ`: так файлы
сортируются в хронологическом порядке в любом файловом менеджере и на GitHub.

Каждый `.tex` — самостоятельный документ со своей преамбулой и собирается
отдельно. Общая преамбула пока не вынесена; когда лекций станет больше
десятка, это первое, что стоит сделать (см. `CONTRIBUTING.md`, раздел
«Что дальше»).

## Локальная сборка

Нужна, только если вы верстаете. Для правки текста достаточно любого
редактора — проверит CI.

1. Установить TeX Live (рекомендуется) или MiKTeX. MiKTeX не содержит Perl,
   без которого не работает `latexmk`, — поставить
   [Strawberry Perl](https://strawberryperl.com/) отдельно.
2. Собрать:

   ```sh
   cd matan
   latexmk -pdf -outdir=build 2026-09-02.tex
   ```

   Результат — `matan/build/2026-09-02.pdf`. Папка `build/` в `.gitignore`.

3. В VS Code с расширением LaTeX Workshop настройки уже в репозитории:
   сборка по сохранению или `Ctrl+Alt+B`, PDF открывается во вкладке рядом.
   Рецепт — `latexmk`; рецепт с `bibtex` не использовать, он падает
   на документах без библиографии.

Документы собираются `pdflatex` (кодировка `T2A`, `babel` с русским).
`xelatex`/`lualatex` не требуются.

## Как вносить правки

Коротко: ветка или форк → правка одной лекции → PR → ревью → мерж.
Ошибки в математике (не опечатки, а неверные утверждения) — через
[Issues](https://github.com/Daniikos/lecture/issues), не через PR.

Подробно — в [`CONTRIBUTING.md`](CONTRIBUTING.md).
