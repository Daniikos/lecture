# Математический анализ

Конспект лекций. Один файл — одна лекция, имя файла — дата лекции.
PDF всех лекций — в релизе
[`latest`](https://github.com/Daniikos/lecture/releases/tag/latest),
файл `matan-<дата>.pdf`.

## Лекции

| Дата | Тема | Разделы | Файл |

При добавлении лекции — добавьте строку сюда в том же PR. Разделы —
это `\section*` из файла, через ` · `.

## Особенности набора

- Компилятор `pdflatex`, кодировка `T2A`, `babel` с русским.
- Диаграммы Эйлера–Венна — макрос `\venn` в преамбуле файла.
- Расхождения с рукописью отмечены в исходнике комментариями `% в оригинале ...`.
